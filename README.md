
# 🚀 Josué Rodríguez Ramírez - Interactive & Multilingual CV

Welcome to my dynamic and interactive Curriculum Vitae repository! This project showcases my professional journey, skills, and projects in a modern, accessible, and multilingual format. Whether you're a recruiter, a fellow developer, or just curious, you can explore my CV directly in your browser or download it as a polished PDF.

## ✨ Features

**🌐 Multilingual Support:** View my CV in three languages:

    -   Spanish (Español)
    -   English
    -   French (Français)
    
**🖥️ Dual Viewing Modes:**

    -   Web Version: Experience an interactive, responsive web page version of my CV directly in your browser.
    -   PDF Version: Generate and download a high-quality, print-ready PDF document of my CV.
    
**🎨 Clean & Professional Design:** A sleek, two-column layout optimized for readability and visual appeal.

**🛠️ Dynamic Tech Stack Badges:** Visually appealing badges for all my known programming languages, frameworks, and tools, loaded as local assets for eliability.

**🚀 Optimized for Performance:** Built with modern React practices and `react-pdf/renderer` for efficient document generation.

## 🎯 Why this approach?

In today's global and digital landscape, flexibility is key. This project aims to provide a seamless experience for anyone reviewing my qualifications, allowing them to choose their preferred language and format. It's not just a CV; it's a demonstration of my front-end development skills, attention to detail, and commitment to user experience.

## 💻 Technologies Used

- **React:** For building the dynamic user interface.
- **@react-pdf/renderer:** A powerful library for generating PDF documents directly from React components.
- **Vite:** A fast and efficient build tool for modern web projects.
- **JavaScript (ES6+):** The core language for application logic.
- **CSS Modules / Inline Styles:** For scoped and maintainable styling.
- **Local Assets:** All tech stack badges are imported locally for robust rendering across different environments.

## 🚀 Getting Started

To get a copy of this project up and running on your local machine for development and testing purposes, follow these simple steps.

### Prerequisites

Make sure you have Node.js and npm (or yarn) installed on your system.

- Node.js (LTS version recommended)
- npm (usually comes with Node.js) or Yarn

### Installation

1. **Clone the repository:**

```bash
    git clone <https://github.com/josueRdgz/mi-cv-react.git>
    cd mi-cv-react
```

2. **Install dependencies:**

```bash
    npm install
    # or
    yarn install
```

### Running the Application

To start the development server:

```bash
npm run dev
# or
yarn dev
```

This will open the application in your browser (usually at `http://localhost:5173`). You'll be greeted with the language selection screen.
